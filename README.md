# Programming Basics - Bài tập tính tuổi (Python)

Dự án lưu trữ bài tập lập trình cơ bản đầu tiên viết bằng ngôn ngữ Python.

## Mô tả bài toán
Viết chương trình cho phép người dùng nhập vào năm sinh từ bàn phím, tính toán số tuổi hiện tại (tính đến năm 2026) và hiển thị kết quả ra màn hình.

## Cách chạy chương trình
1. Mở thư mục chứa dự án trong Terminal hoặc Visual Studio Code
2. Gõ câu lệnh sau vào Terminal để chạy chương trình: python bai1.py
3. Nhập năm sinh của bạn (ví dụ: 2005) và nhấn Enter để xem kết quả.
